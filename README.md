# PULSE — Gym Membership & Fitness Tracker System

A full-stack MERN project (MongoDB, Express, React, Node.js) built for the
CSE-323 Web Programming project proposal: user auth, membership plans, BMI
calculator, workout tracker + history, and an admin dashboard for member
management — plus a progress-chart and streak view for extra polish.

See `SETUP_GUIDE.md` for step-by-step local setup and the 7-commit Git
workflow to use for submission.
